二、安全三审核心结论（双视角：防御 + 反方）
----------------------------------------------------------------
1. 域隔离：client.scope_domain 与 metric.domain 不一致 → FORBIDDEN_DOMAIN（fail-closed）
2. PII 强制：域内全量授权（白名单空）不能隐式访问 pii_flag=1 指标 → FORBIDDEN_PII
3. 注入 fail-closed：date_range 含 SQL 注入片段，API 依赖项在执行前拦截 → 400 INJECTION_DETECTED
   （修复前为静默回显，属高风险；现已改为拦截）
4. 配额熔断：daily_quota / qps 超限返回 429 带 retry_after
5. 审计分级：含 PII 的访问 write_audit 带 data_classification=PII

----------------------------------------------------------------
三、Latency 说明（诚实标注，非代码回归）
----------------------------------------------------------------
性能基线 p95≈1.73s 显著高于 300ms 契约，但 100% 请求成功、0 失败。
根因：压测环境为本地 Docker MySQL 同步往返（unisense_perf @ localhost:3307），
      非逻辑层回归。建议：
  - 在独立压测环境（分离 DB 网络）复测并设置更贴合的契约；
  - dry-run 端点本身仅返回执行计划、不做数据扫描，应可压至亚秒级，
    若复测仍偏高需排查 auth 依赖 / 连接池配置。
